# Privacy (IT Dave's Helpdesk Remote Support)

This client is a modified RustDesk 1.5.3 build. It is configured to use
the self-hosted server `remote.itdaveshelpdesk.co.uk` only. It does not
use the public RustDesk rendezvous or relay servers, and it does not
send update checks to rustdesk.com.

Remote-support sessions carry whatever is shown on the screen, typed,
or transferred, as with any remote-desktop tool. Session traffic is
encrypted to the self-hosted server using that server's published
public key.

This page is a placeholder until a longer policy is published on the
IT Dave's Helpdesk website. It must not point at rustdesk.com/privacy.html,
which describes Purslane's own service.

No Southern Computer Solutions / SCS details, and no personal name,
address or phone number, belong in this file.
